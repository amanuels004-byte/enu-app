# Enu roadmap

## Prototype implemented
- Local music library and playback
- Favorites and listening history
- Offline faith-chat fallback
- Saved local conversation
- Voice input/output hooks
- Local profile

## Remaining before a public release
- Real AI service through a secure backend
- Real sign-in, password reset, and account deletion
- Optional encrypted cloud sync
- Curated, licensed music catalog or user-owned imports
- Android app icon, package ID, privacy policy, and store listing
- Accessibility, offline, and device compatibility tests
